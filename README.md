# CLASS-GEO-Lens

Public GEO-Lens implementation for CLASS-based cosmological validation and Hubble tension studies.

## Overview

CLASS-GEO-Lens is an experimental public repository designed to expose the GEO-Lens implementation layer used in the GEO (Hidden Geometry Framework) cosmological studies.

The project serves as an entry point for researchers, cosmologists, and CLASS users interested in reproducing or evaluating GEO-Lens based modifications and validation workflows.

## Purpose

This repository provides:

* GEO-Lens implementation pathway
* CLASS integration references
* Reproducibility resources
* Hubble tension validation materials
* Public access to GEO-Lens experiments
